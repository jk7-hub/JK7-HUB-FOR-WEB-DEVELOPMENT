JOINs
SELECT u.name, o.total
FROM users u
INNER JOIN orders o ON u.id = o.user_id;  -- Matching rows only

SELECT u.name, o.total
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;   -- All users, null if no order

SELECT u.name, o.total, p.title
FROM users u
JOIN orders o ON u.id = o.user_id
JOIN products p ON o.product_id = p.id
WHERE o.total > 100 ORDER BY o.total DESC LIMIT 5;

09Security
SQL Injection Prevention
// WRONG — NEVER DO THIS!
$q = "SELECT * FROM users WHERE id = $_GET['id']";

// RIGHT — Prepared Statements
$stmt = $pdo->prepare("SELECT * FROM users WHERE id=?");
$stmt->execute([$_GET['id']]);

// Also sanitize types
$id = intval($_GET['id']);
Warning
Never concatenate user input directly into SQL!
XSS & Passwords
// XSS Prevention
$clean = htmlspecialchars($_POST['input'], ENT_QUOTES);
$clean = strip_tags($input);

// Password Hashing (bcrypt)
$hash = password_hash($password, PASSWORD_BCRYPT);
if (password_verify($input, $hash)) {
  echo "Login success!";
}

// CSRF Token
session_start();
$token = bin2hex(random_bytes(32));
$_SESSION['csrf'] = $token;

13Interview Questions
HTML & CSS
Difference between div and span?
div is block-level (full width), span is inline (content-width). Use div for layout, span for inline text styling.
Explain the CSS Box Model.
Every element: content → padding → border → margin. With box-sizing:border-box, padding and border are included in the width.
Flexbox vs Grid?
Flexbox is 1D (rows OR columns). Grid is 2D (rows AND columns). Flex for components, Grid for page layout.
What is CSS specificity?
Priority: !important > inline > #id > .class > tag. Higher specificity wins when rules conflict.
MySQL
WHERE vs HAVING?
WHERE filters rows before grouping. HAVING filters groups after GROUP BY. Use HAVING with COUNT, SUM, etc.
INNER JOIN vs LEFT JOIN?
INNER returns only matching rows. LEFT returns all left-table rows; non-matches get NULL on the right side.
JavaScript
let vs const vs var?
var: function-scoped, hoisted. let: block-scoped. const: block-scoped, can't be reassigned. Prefer const, then let.
What is a closure?
A function that remembers variables from its outer scope even after that scope has returned. Used for data privacy.
What is event bubbling?
Events fire on the target and then bubble up to parent elements. Use e.stopPropagation() to prevent this.
What is a Promise?
An object representing eventual completion or failure of async work. States: pending → fulfilled or rejected. Use .then()/.catch() or async/await.
Security
What is SQL Injection?
Attacker injects malicious SQL via inputs. Prevent with prepared statements. Never concatenate user input into SQL.
What is XSS?
Cross-Site Scripting: attacker injects scripts into pages. Prevent by escaping output with htmlspecialchars() and sanitizing all input.
